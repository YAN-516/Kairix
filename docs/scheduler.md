# Kairix MLFQ-lite Scheduler

Kairix 当前调度器采用简化版多级反馈队列：

- 4 个 ready queue，`Q0` 最高优先级，`Q3` 最低优先级。
- 队列之间按优先级选择，队列内部采用 round-robin。
- 每级时间片依次为 2、4、8、16 个 timer tick。
- timer 抢占时扣减当前任务剩余时间片；时间片耗尽后任务降一级。
- 主动 yield 不降级，只回到当前队列参与轮转。
- 阻塞/睡眠任务被唤醒时提升一级，提高交互型和 I/O 型任务响应速度。
- ready 队列中等待过久的任务会 aging 提升一级，避免低优先级任务饿死。

这个策略比固定 FIFO/固定优先级更能区分交互型任务和 CPU 密集型任务，同时实现成本较低，适合当前内核阶段。
